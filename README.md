# Limits AI

Приложение (PWA) для отслеживания лимитов ИИ-сервисов: Claude, ChatGPT, Gemini, Cursor, Perplexity и любых других.
Показывает, сколько запросов израсходовано, сколько осталось и когда лимит восстановится.

Адрес после публикации: https://andreyroyal.github.io/Limits-AI/

## Возможности

- Пресеты популярных сервисов. Все параметры можно менять, лимит запросов указывать необязательно.
- Пять типов сброса:
  - **окно от первого запроса**: окно на N часов открывается первым запросом (как 5-часовая сессия Claude);
  - **скользящее окно**: каждый запрос «сгорает» через N часов;
  - **каждый день / неделю / месяц** в заданное время.
- Кнопка «Лимит кончился» с точным временем восстановления, которое показал сервис (или расчётным).
- Обратный отсчёт до сброса и уведомление, когда лимит восстановлен.
- Работает офлайн и ставится на телефон как приложение: в Chrome нажмите «Добавить на главный экран».
- Данные хранятся только на устройстве (`localStorage`). Для бэкапа и переноса есть экспорт и импорт в JSON.

Ограничение: браузер не умеет показывать уведомление по расписанию, когда приложение полностью закрыто.
Уведомления приходят, пока приложение открыто или свёрнуто в фоне.

## Разработка

Сборки нет, это обычные HTML/CSS/JS-модули в папке `app/`.

```bash
cd app && python3 -m http.server 8000
```

```bash
npm test
```

Тесты логики лимитов лежат в `tests/`, запускаются встроенным `node --test`.

## Публикация

Workflow `.github/workflows/pages.yml` при пуше в `main` прогоняет тесты и публикует папку `app/` на GitHub Pages.
Один раз включите: **Settings → Pages → Source: GitHub Actions**.
